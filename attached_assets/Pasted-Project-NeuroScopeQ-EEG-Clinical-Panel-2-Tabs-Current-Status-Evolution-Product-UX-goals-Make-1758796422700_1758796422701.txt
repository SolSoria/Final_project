Project: NeuroScopeQ — EEG Clinical Panel (2 Tabs: Current Status & Evolution)
Product/UX goals
Make EEG legible at the bedside (Current Status) and comparable across sessions (Evolution).
No spectrograms, no raw traces. Use severity bands, quality gates, and short clinical notes.
Two modes:
Simulation mode (replays synthetic, TUH-like cases from Mongo).
Live/LSL mode (reads real-time snapshots from an LSL Gateway service).
Evolution tab must be identical across modes (always reads from Mongo sessions).
All UI strings, labels, database content, and comments in English.
Tech stack
Frontend: React + TypeScript + Vite, TailwindCSS, Recharts
State: Zustand (UI state) + React Query (server data)
Backend: Node + Express, Mongoose (MongoDB)
DB: MongoDB (two databases: neuroscopeq_sim and neuroscopeq_live)
Seeding: script that creates 5 realistic cases with sessions & RT snapshots
Testing: Vitest + React Testing Library
Tooling: ESLint + Prettier

Mongoose schema (shared by both modes)
/src/api/models.ts
import { Schema, model, models } from "mongoose";

export const Cohort = ["PEDS","ADULT","GERIATRIC"] as const;
export const Setting = ["AMBULATORY","WARD","ICU"] as const;
export const Reactivity = ["present","uncertain","absent"] as const;
export const Continuity = ["continuous","discontinuous","burst_suppression","suppressed"] as const;
export const ACNS = ["LPD","GPD","LRDA","GRDA"] as const;
export const Side = ["L","R"] as const;

const ConditionSchema = new Schema({ name: String, status: { type: String, enum: ["active","resolving","historical"], default: "active" }, startedAt: Date },{ _id:false });
const MedicationSchema = new Schema({ drug: String, dose: String, route: String, start: Date, end: Date },{ _id:false });
const ClinicalEventSchema = new Schema({ ts: Date, kind: String, note: String },{ _id:false });

const PatientSchema = new Schema({
  name: String, age: Number, sex: { type: String, enum:["M","F","X"] },
  cohort: { type: String, enum: Cohort }, setting:{ type: String, enum: Setting },
  bed: String, conditions:[ConditionSchema], medications:[MedicationSchema]
},{ timestamps:true });

const SessionSchema = new Schema({
  patientId: { type: Schema.Types.ObjectId, ref: "Patient", index: true },
  date: { type: Date, index: true },
  encephalopathyScore: Number, deltaPct: Number, adr: Number, sef95: Number,
  contContinuous: Number, contDiscontinuous: Number, contBurst: Number, contSuppressed: Number,
  reactivityLight: { type: String, enum: Reactivity }, reactivitySound: { type: String, enum: Reactivity }, reactivityTactile:{ type: String, enum: Reactivity },
  seizureBurdenMinPerHour: Number, seizureEvents: Number,
  acnsRatePerHour: Number, acnsPattern: { type: String, enum: ACNS }, acnsSide: { type: String, enum: Side },
  asymmetryIdx: Number, asymmetrySide: { type: String, enum: Side },
  artifactPct: Number, minutesValid: Number,
  clinicalEvents: [ClinicalEventSchema]
},{ timestamps:true });

const RealtimeSchema = new Schema({
  patientId: { type: Schema.Types.ObjectId, ref: "Patient", index: true },
  ts: { type: Date, default: Date.now, index: true },
  artifactPct: Number, minutesValid: Number,
  reactivity: { type: String, enum: Reactivity },
  pdrHz: Number, continuity: { type: String, enum: Continuity },
  asymmetryIdx: Number, asymmetrySide: { type: String, enum: Side },
  deltaPct: Number, adr: Number, sef95: Number,
  acnsPattern: { type: String, enum: ACNS }, acnsSide: { type: String, enum: Side },
  seizureBurdenMinPerHour: Number, seizureEvents: Number
},{ timestamps:true });

SessionSchema.index({ patientId:1, date:-1 });
RealtimeSchema.index({ patientId:1, ts:-1 });

export const Patient = models.Patient || model("Patient", PatientSchema);
export const Session = models.Session || model("Session", SessionSchema);
export const RealtimeSample = models.RealtimeSample || model("RealtimeSample", RealtimeSchema);
DB connection & mode switching
/src/api/db.ts
import mongoose from "mongoose";

let conn: typeof mongoose | null = null;

export function getMongoUri(){
  return process.env.MODE === 'live'
    ? process.env.MONGODB_URI_LIVE!
    : process.env.MONGODB_URI_SIM!;
}

export async function connectDB() {
  if (conn) return conn;
  const uri = getMongoUri();
  conn = await mongoose.connect(uri);
  return conn;
}
Backend (Express) with mode-aware endpoints
/src/api/routes.ts
import express from "express";
import fetch from "node-fetch";
import { connectDB } from "./db";
import { Patient, Session, RealtimeSample } from "./models";

export const router = express.Router();

router.get("/api/patient/:id", async (req, res) => {
  await connectDB();
  const p = await Patient.findById(req.params.id).lean();
  if (!p) return res.status(404).json({ error: "Patient not found" });
  res.json(p);
});

router.get("/api/sessions/:id", async (req, res) => {
  await connectDB();
  const sessions = await Session.find({ patientId: req.params.id }).sort({ date: 1 }).lean();
  res.json(sessions);
});

router.get("/api/realtime/:id", async (req, res) => {
  await connectDB();
  if (process.env.MODE === "live") {
    try {
      const r = await fetch(`${process.env.LSL_GATEWAY_URL}?patientId=${req.params.id}`, { timeout: 1500 as any });
      if (r.ok) return res.json(await r.json());
    } catch (_) { /* fall through */ }
  }
  const snap = await RealtimeSample.findOne({ patientId: req.params.id }).sort({ ts: -1 }).lean();
  res.json(snap || null);
});

const d = (s:string)=> new Date(s);
const jitter=(m:number,s:number)=> Math.max(0, m + (Math.random()*2-1)*s);

async function rtBurst(patientId:any, n=12, base:any={}){
  for (let i=0;i<n;i++){
    await RealtimeSample.create({
      patientId,
      ts: new Date(Date.now() - (n-i)*5000),
      artifactPct: jitter(base.artifactPct ?? 12, 6),
      minutesValid: 20,
      reactivity: base.reactivity ?? "present",
      pdrHz: base.pdrHz ?? jitter(10,0.8),
      continuity: base.continuity ?? "continuous",
      asymmetryIdx: jitter(base.asymmetryIdx ?? 0.08, 0.04),
      asymmetrySide: base.asymmetrySide ?? undefined,
      deltaPct: jitter(base.deltaPct ?? 12, 5),
      adr: jitter(base.adr ?? 1.3, 0.3),
      sef95: jitter(base.sef95 ?? 13.5, 1.0),

      acnsSide: base.acnsSide ?? undefined,
      seizureBurdenMinPerHour: base.seizureBurden ?? 0,
      seizureEvents: base.seizureEvents ?? 0
    });
  }
}

Frontend behavior (key points)
Layout: Header (Patient badge, Mode badge, Cohort chips, Quality) + Tabs.
ModeBadge:
MODE=simulation → “Simulation (TUH-like)” ⚪️
MODE=live → ping /api/realtime/:id every 10s. Success → “LSL: Connected” 🟢, otherwise 🟥 “Disconnected”
Current Status tab:
Pull /api/realtime/:id every RT_POLL_INTERVAL_MS.
Each MetricCard: Title · Value/Unit · Severity band (3–4 bins) · ReferenceBand (cohort bands) · ConfidenceBar (artifact% + minutes valid) · short clinical note.
If artifactPct > thresholds.artifact.warnMax → gray out interpretive cards; show “Interpretation limited by artifacts.”
Evolution tab:
Pull /api/sessions/:id.
Charts:
Encephalopathy (line + cohort bands).
Delta% (line + age/cohort band).
ADR & SEF95 (sparklines).
Continuity (100% stacked bars).
Reactivity (heatmap by stimulus).
Seizure burden (bars + cut lines).
ACNS rate (line) + pattern/side chips.
Asymmetry (line + L/R badges).
Quality (bars + recurrent channels).
Vertical markers for clinical events (sedation start/stop, AED change, etc.).
Summary cards under each chart with: current value, Δ vs previous, slope (improving/worsening), one-line clinical note.
Tests (minimum)
Render MetricCard with proper bin given thresholds (adult vs geriatric).
When artifactPct > 30%, interpretive cards are dimmed and guard text appears.
Evolution “Encephalopathy” shows bands and tooltips with Δ/Δ%.
ModeBadge switches labels/colors with MODE and connectivity.
Acceptance criteria
Two tabs: Current Status (real-time) and Evolution (trends).
No spectrograms/raw traces anywhere.
Simulation mode uses Mongo neuroscopeq_sim with 5 TUH-like cases; Live mode proxies LSL Gateway for RT only.
Evolution tab is identical across modes (same API/DB).
Severity bands & clinical text are cohort-aware and consistent.
Quality gate dims cards when artifacts are high.
All UI and data in English.
